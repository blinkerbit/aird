# Code of conduct

This project is open to bug reports, feature requests, and pull requests.

- Be specific and respectful in issues and reviews.
- Critique the change, not the person.
- Keep security reports private. See [SECURITY.md](SECURITY.md).
- Do not post access tokens, passwords, or private file contents.

Maintainers may edit or close reports that do not follow this, and may block repeat abuse.
